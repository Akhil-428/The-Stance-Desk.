# Technical decisions

Audit IDs (K1-K18, H-1, M-3, ...) refer to [AUDIT_SUMMARY.md](AUDIT_SUMMARY.md). Each decision states what the original project did, what we did, and why. "Faithful" means it matches the original notebook.

| # | Topic | Original | This implementation | Why |
|---|---|---|---|---|
| D0 | Python / stack | Python 3.7 on a Colab TPU, torch 1.9 + torch_xla, transformers 4.12.5 | Python 3.13 virtual environment; torch 2.14.1 (CUDA 12.6 build for GPU training); transformers 5.23.0 | The old pins cannot be installed on current Python versions and carry published remote-code-execution advisories (audit H-1, M-3; see `AUDIT_SUMMARY.md`). The cu126 build was chosen because it runs on NVIDIA drivers that support CUDA 12.x (verified on driver 551.76 with an RTX 3050 via `torch.cuda.is_available()`, `sm_86` in the arch list and an fp16 matmul). CUDA 13 builds need a much newer driver and were not used. |
| D1 | BERT input | One string, `headline + "[SEP]" + body`; segment ids all 0 | Sentence pair: `tokenizer(headline, body, truncation="longest_first")` | Same tokens and the same 512-token limit, but BERT's segment embedding now marks which part is the headline, and the headline is never truncated. This is standard BERT practice and was recommended by the audit (K8). It is the one deliberate input-format change. |
| D2 | Class imbalance | Plain cross-entropy | Plain cross-entropy (**faithful**) | Kept the original. Class weights are a possible future improvement for *disagree*. |
| D3 | Model selection | Validation loss, on an unseeded row-level split | **Validation macro-F1**, on a split grouped by Body ID | Macro-F1 reflects the minority classes the task cares about (audit K9). |
| D4 | Split | `train_test_split(0.2)`, no seed, no stratification | `StratifiedGroupKFold(10)`, fold 0 (90/10), groups = Body ID, seed 42, indices saved to `data/splits/` | Removes train/validation leakage through shared article bodies (audit G-P1, G-L2). The official test set is used once, at the end. |
| D5 | Hyperparameters | 3 epochs, batch 16, LR 5e-5 (Trainer default), warm-up 500, weight decay 0.01 | Same values; effective batch 16 as micro-batch 8 × 2 accumulation, fp16, gradient clipping 1.0 (the Trainer default) | Fits in the 3050's 6 GB VRAM (3.75 GB measured). |
| D6 | Training loop | HF `Trainer`, TPU | Small explicit PyTorch loop (`train_bert.py`) | Fewer moving parts on brand-new library versions. It adds a time budget (graceful stop + save) so a run can be bounded, and validates twice per epoch. |
| D7 | Checkpoint format | `pytorch_model.bin` (pickle) on a private Drive | `model.safetensors` only; loader refuses `.bin`/`.pt`; `trust_remote_code=False`; offline loading | Audit H-1 / L-1. |
| D8 | Pretrained weights | `bert-base-uncased` (unpinned) | `google-bert/bert-base-uncased` @ `86b5e093…`, safetensors + config + tokenizer only; SHA-256 matches HF's published hash | Provenance. |
| D9 | Baselines | OvR LR / BNB on concatenated bag of words; argmax over 0/1 output; encoder names swapped; vectoriser fit before split; trained on 70% | Same models re-implemented with bugs fixed: `argmax(predict_proba)`, correct names, `Pipeline` fit on the training fold, BNB reported once, same grouped split. `min_df=2` added for memory. | Audit K3–K5, K7. |
| D10 | CPU engine | (none) | Multinomial LR on headline/body TF-IDF + cosine + overlap/refuting features (`features.py`) | The bag-of-words baselines can't model the headline–body relationship and barely beat "always unrelated". This engine is a clearly labelled, different design inspired by the official FNC-1 baseline features. |
| D11 | LR persistence | n/a | `joblib` (pickle) written by our own script, loaded only after a SHA-256 check against `model_info.json` | A pragmatic exception to the "no pickle" preference: the file is created locally and integrity-checked. It is never loaded from elsewhere. |
| D12 | Scoring | `scorer.py` (cp1252 crash on Windows, silent truncation) | `evaluation.py` re-implements the FNC-1 rule. A test reproduces the audited 10,068.25 / 11,651.25 / 0.903750 / macro-F1 0.691 on the committed `BERT.csv`. | Audit H-section and K10. |
| D13 | Web framework | (none) | Streamlit 1.67 multipage (`st.navigation`), bound to localhost:8501, telemetry off, browser opens automatically | Python-only and simple to run. |
